# Featured Project

## CRC-8 Instruction Extension on a 5-Stage Pipelined MIPS32 Processor

Custom instruction added to a **pipelined MIPS32 processor** and deployed on a **Spartan-6 FPGA**.

### Key Highlights

* Custom **CRC-8 instruction** added to the MIPS ISA
* Implemented inside a **5-stage pipelined processor**
* Hardware CRC computation using polynomial `0x07`
* FPGA implementation on **Xilinx Spartan-6**
* 32-bit input via switches and push buttons
* Output displayed on **16×2 LCD**

### Technologies Used

Verilog • FPGA • Processor Architecture • Digital Logic • RTL Design
